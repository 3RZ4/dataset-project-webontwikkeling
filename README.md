# Dataset Project Webontwikkeling

Een webapplicatie gebouwd met Node.js, Express, TypeScript, EJS en MongoDB.

## Functionaliteiten

- Lijst van muziekartisten bekijken
- Zoeken op naam
- Detailpagina per artiest
- Login en registratie systeem
- Admin kan artiesten bewerken
